
# Sprint 3, Task 2: Software Construction Patterns in Java

## Description
This project focuses on exploring foundational software design patterns through practical examples in Java. Each level introduces a different pattern and a scenario that demonstrates its use in a real-world context. The goal is to encourage thoughtful software architecture and modular design.

### Level 1: Builder Pattern – Pizza Ordering System
Design a system for managing pizza orders using the Builder pattern. The system should allow flexible configuration of pizzas based on size, dough type, and ingredients. The implementation should demonstrate how the pattern supports customizable object creation and separation of concerns.

### Level 2: Observer Pattern – Stock Market Alerts
Create a notification system where a central stock agent informs multiple agencies about market changes. The Observer pattern is used to establish dynamic relationships between the notifier and its listeners, enabling real-time updates and decoupled communication.

### Level 3: Callback Pattern – Payment Gateway Simulation
Simulate a payment gateway that can process different payment methods without knowing their internal details. The Callback pattern allows the gateway to invoke payment logic and return control to the initiating system, demonstrating flexibility and abstraction in execution flow.
